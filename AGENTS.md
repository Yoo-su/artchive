## Agent skills

### Issue tracker

Issues and PRDs for this repo live as GitHub issues. See `docs/agents/issue-tracker.md`.

### Triage labels

The standard five triage labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`) are mapped directly. See `docs/agents/triage-labels.md`.

### Domain docs

The repo uses a single-context layout for domain context and ADRs. See `docs/agents/domain.md`.
